**Gathered:** 2026-05-19

<domain>
## Phase Boundary

Évaluation de la technologie de rendu à utiliser pour les overlays LMU avant d'exécuter la Phase 2 (UI Customization). La question centrale : WPF (actuel) vs SkiaSharp 3.119.2 + D3D11 backend vs D3D11 natif — quelle approche doit guider l'architecture de Phase 2 ?

Cette phase est un **proof-of-concept d'évaluation** — elle produit une recommandation technique documentée, pas une migration complète.

</domain>

<decisions>
## Implementation Decisions

### Périmètre d'évaluation
- Technologies candidates : WPF (statu quo), SkiaSharp 3.119.2 + D3D11 backend, D3D11 natif
- Évaluation ciblée sur un overlay unique (pas migration complète)
- Critères prioritaires : compatibilité VR (OpenXR swapchain), performance frame rate, maintenabilité C# WPF codebase

### Lien avec les requirements
- **VR-01** : Proof-of-concept pipeline SkiaSharp 3.119.2 + D3D11 backend sur un overlay unique avant migration complète
- **VR-02** : Migration du rendu VR de `RenderTargetBitmap` vers rendu direct dans textures swapchain OpenXR (horizon post-Phase 2)

### Contrainte architecture
- L'évaluation doit préciser si Phase 2 (UI-01, UI-02, UI-03, UI-04) peut être implémentée en WPF pur, ou si SkiaSharp/D3D11 est nécessaire dès Phase 2
- Code existant : `BaseOverlayWindow` hérite de `Window` WPF — toute migration D3D11 impacte cette classe centrale

### Claude's Discretion
- Méthode de benchmarking exacte (frame time measurement, GPU profiler, etc.)
- Overlay choisi pour le PoC
- Format du rapport de recommandation
- Critères de scoring des options

</decisions>

<specifics>
## Specific Ideas

- Le PoC SkiaSharp + D3D11 doit tourner sur le même overlay que les overlays actuels pour une comparaison fair
- La décision impacte directement l'architecture de Phase 2 — cette phase débloque Phase 2

</specifics>

<deferred>
## Deferred Ideas

- Migration complète vers SkiaSharp/D3D11 (si recommandé) → Phase 2+ ou phase dédiée post-Phase 2
- VR-02 (rendu OpenXR swapchain complet) → v2 après stabilisation Phase 2

</deferred>
